# 南京东部战区总医院有卵子库可以申请供卵做试管吗？

> 更新时间：2026-09-16 (UTC+8)

我已经做了三次试管了，一次次的失败都给我沉重的打击。我最近在论坛发了一些自己的经历，有一些做试管的姐妹都来安慰我。其中有一个姐妹说她之前就是那样，后来去申请供卵做试管就成功了，建议我也去试试。我觉得可以，但是我要申请供卵做试管的话，南京东部战区总医院有卵子库吗？ 
查看全部内容

如果想申请供卵做试管可以去南京东部战区总院，但是该院没有卵子库。国内任何一家正规做试管的医院都没有专门的卵子库，在我国成立卵子库是违法的。南京东部战区总院的卵源主要是来自于在该院治疗的患者，在有20枚卵子的情况下，自留15枚做试管成功后，将其余几枚卵子自愿捐献出来的。能够满足条件进行捐献的患者很少，而且愿意捐献的人也比较少，所以医院的卵源都很稀缺。

南方东部战区总医院目前开展了一代、二代、三代试管婴儿技术，这几项技术都支持做供卵试管，而且东部战区总医院试管婴儿成功率在50％左右，不管是做普通试管还是供卵试管都是南京市试管成功率较高的医院。虽然在该院可以申请供卵做试管，但需要申请供卵做试管还需要具备以下条件：

- 1. 受卵女方要确定有卵巢功能缺失、卵巢排卵障碍或卵子质量极差等症状；
- 2. 受卵女方已经做过三次及以上人工授精失败，才能做供卵试管；
- 3. 受卵男方的精子质量比较好，情况不好需要治疗好后才能开始做供卵试管；
- 4. 患者双方要具备有效的结婚证、身份证和准生证，三证缺一不可。
在南方东部战区总医院申请做试管一般都需要等待3-5年的时间，如果确实需要申请供卵做试管可以去南京的多个医院申请供卵，增加供卵的机会。除此之外，患者要有比较好的经济基础，因为供卵试管的价格比一般试管要贵。
