# 感染新冠后，耳朵不适怎么办？耳鼻喉科专家来支招

> 更新时间：2026-09-17 (UTC+8)

**官方微信平台，点击上方欢迎订阅**

近期，耳鼻喉咽喉科专家收到不少朋友咨询，感染新冠后耳朵里面疼，出现耳闷胀感，有的还感觉到自身听力有所下降。**如果出现这些不适应该怎么办呢？小熊医院耳鼻喉专家来支招。**

**耳痛**

**咽痛剧烈引起耳朵牵扯痛**

**处理方法：**口服布洛芬，咽痛缓解后耳痛自然会缓解。

**急性中耳炎发作**

**处理方法：**氧氟沙星滴耳液滴耳。

**耳闷**

主要表现为擤鼻涕后耳闷胀感。

**处理方法：**

**1.掌握正确的擤鼻方法。**先按压单侧鼻翼，单侧擤鼻后，再按压对侧鼻翼，双侧鼻腔单独清理。或者用生理盐水清洗鼻腔。

**2.使用鼻喷剂，**减轻鼻腔阻塞例如减充血剂、抗组胺等鼻喷剂，如达芬霖、爱赛平，或者类固醇类鼻喷剂等。

**听力下降**

主要表现根据听力损失的严重程度而不同，可以是稍稍听力下降，听声音变调，耳鸣，到完全听不到，可以单侧发作，也可以双侧发作。可以将手机声音调小，自己大概判断听力状况，网络上也有相关的听力测试的小程序。确诊要到医院耳鼻喉科进行听力评估。

**处理：**如果明确突发性听力下降，需要口服糖皮质激素。
