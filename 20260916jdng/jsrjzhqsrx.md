# 什么是人工授精？

> 更新时间：2026-09-16 (UTC+8)

什么是人工授精？

人工授精是指把丈夫的或者供精者的精子通过非性交的方式，人工注射送进女性生殖道内，让精子与卵子自然结合，达到妊娠的一种辅助生殖技术。

根据所用精液来源的不同可分为两类。

①夫精人工授精：用丈夫精液进行的人工授精。

②供精人工授精：用他人的精液进行的人工授精。

不过，人工授精的前提是：女方输卵管通畅（输卵管造影）。

**1**

**什么人适合做人工授精呢？**

**1、夫精人工授精的适合人群**

**1、性交困难或精液不能进入阴道者**

男性尿道严重下裂，严重早泄、阳痿、逆行射精症、性交时不射精者。

女性性交时阴道痉挛，阴道解剖结构异常（包括道闭锁、阴道斜隔、阴道纵膈、阴道横隔等）。

**2、精子在女性生殖道中运行障碍者**

子宫颈管狭窄、粘连，宫颈黏液少而黏稠，宫颈锥形切除术后，严重的宫颈陈旧性裂伤，子宫颈肌瘤，子宫位置异常（过度前屈或后屈）等妨碍精子的正常上行游走。

**3、精液检查轻度或中度异常（至少2次精液检查结果）**

①精子计数少于20 x 106/mL

②精液量异常，精液量>8mL或<1 mL

③精子活动率低下，畸、弱精子症

④精液液化不全或不液化

**4、免疫性不孕**

①女性通过抗精子抗体机制不孕，如补体介导的精子毒性，精子在宫颈黏液中的制动，干扰顶体反应与获能，直接妨碍受精。

②男性免疫性不育精液存在抗精子抗体，施行人工授精，精液必须经实验室处理。

**5、不明原因不孕**

女方卵巢功能、输卵管等检查未见异常，男方精液检查未见异常，有正常同房仍未怀孕者。

**2、供精人工授精的适合人群**

**1、绝对性男性不育**

如无精子症、死精子症、先天性睾丸发育不良等。

**2、男方携带不良的遗传基因**

如精神病、癫痫、严重的家族性遗传病如黑蒙性痴呆等。男方患常染色体病，如多指、趾及并指、趾畸形等。

**3、不能治愈的少、弱、畸形精子症**

**2**

**在什么情况下不能做人工授精呢？**

·1、女方有全身性疾病或传染病：

如严重心脏病、肾炎、肝炎等。

2、女方生殖器官严重发育不全或畸形：

如子宫发育不全、严重子宫畸形或子宫畸形曾导致反复流产者。应首先行子宫畸形矫治术后视情况试行人工授精。

3、生殖器官炎症、泌尿生殖系统感染或性传播疾病。

4、一方患有严重遗传、身体或精神疾病。

5、一方接触致畸量的射线、毒物、药品，并处于作用期。

6、一方有吸毒等严重不良嗜好。

7、输卵管欠通畅。

8、女方无排卵。

9、夫妇双方对人工授精有顾虑者。

**如果人工授精失败了，应该怎么办呢？**

若进行2次或以上的人工授精均未孕受孕，则可进行试管助孕。
